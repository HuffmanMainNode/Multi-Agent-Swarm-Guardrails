# Known Limitations

The initial release has no external identity authentication, revocation service, signed policy, persistent replay cache, full delegation attenuation, independent guardian, protected executor, OS sandbox, egress firewall, hardware attestation, proof of complete mediation, signed evidence, trusted timestamp, remote immutable log, human approval binding, semantic prompt-injection engine, legality classifier, recovery orchestration, framework adapters, fuzz/load/penetration testing, or independent security assessment.

The Python package is an experimental reference for deterministic local policy evaluation, a simple hash-chain evidence format, and repository structure verification. It is not production-ready security infrastructure and must not be the only control for high-impact actions.
