# Code of Conduct

We are committed to a respectful, welcoming, harassment-free project environment. Criticize ideas, not people; evaluate evidence; protect private information; and welcome constructive disagreement.

Harassment, threats, discrimination, doxxing, intimidation, deliberate disruption, and publishing private information are unacceptable. Maintainers may remove contributions or restrict participation. Report concerns privately to the repository maintainer through a verified channel. Reports will be handled discreetly.
