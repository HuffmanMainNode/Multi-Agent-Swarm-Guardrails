# Governance

MASG is currently maintainer-led and experimental. MrCakes931 is responsible for project direction, contract stewardship, releases, and repository administration.

Decisions prioritize reproducible evidence, compatibility without weakening contracts, offline/local-first use, mature standards over bespoke components, a small core, and explicit uncertainty.

Substantial changes should use issues or ADRs. Normative contract changes require versioning and migration analysis. Releases require tests, dependency/license review, provenance review, and honest assurance statements. Community steering and succession are future work, not current governance structures.
